# SIL Topic Naming RU — корректирующий патч 1.2.1

Патч подготовлен после проверки фактических `group_topic_profiles.csv`, `topic_candidates.csv` и распределения 1 870 публикаций по десяти сообществам.

## Основные исправления

- `naming_confidence` теперь рассчитывается независимо от `topic_profile_status`.
- `naming_confidence_score` — составная эвристическая оценка доказательств названия; `top_term_naming_score` сохраняет рейтинг ведущего термина.
- Второстепенные термины влияют на название только при достаточной поддержке и/или контрастности.
- Добавлено распознавание VLA и ISAC; расширен русский словарь научной терминологии.
- Минимальная доля кандидата снижена с 4% до 3%; добавлены экономические однословные понятия.
- В `topic_candidates.csv` различаются буквальные совпадения и контекстные онтологические признаки.
- В панели показаны происхождение перевода и разложение поддержки по типам доказательств.

## Установка

Распакуйте архив. Из корня проекта `Scientific_Intelligence_Lab_General_1870` выполните:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\SIL_Topic_Naming_RU_Patch_1.2.1\APPLY_TOPIC_NAMING_RU_PATCH_1.2.1.ps1 -ProjectRoot (Get-Location).Path
```

Установщик проверяет структуру проекта и резервирует все заменяемые файлы в `.sil_backups`.

## Проверка и запуск

```powershell
$env:PYTHONPATH = "src;."
.\.venv\Scripts\python.exe -m py_compile topic_naming.py topic_understanding.py run_topic_understanding.py dashboard\app.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\RUN_TOPIC_UNDERSTANDING.ps1
.\START_DASHBOARD.ps1
```

Пересчёт профилей не требует повторного построения эмбеддингов или графа. Исходные назначения сообществ не изменяются.
