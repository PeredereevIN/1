# Изменения: модельное семантическое именование

## Что добавлено
- Добавлен локальный Ollama-клиент на стандартной библиотеке Python (`urllib`), без установки дополнительных Python-пакетов.
- Модель по умолчанию: `qwen3.5:4b`.
- При старте проверяются доступность API, наличие выбранной модели, её digest и версия Ollama.
- После завершения Leiden для каждого сообщества формируются русское и английское названия, краткое описание и примечание о неоднородности.
- Evidence включает ключевые фразы YAKE/RAKE/contrastive TF-IDF, домены, шесть центральных публикаций и доступные фрагменты их аннотаций.
- В Streamlit выводятся описание, примечание и метод именования.
- В `topic_label_generation.json` сохраняются поданные модели evidence и её ответы.
- Режим `-Labeler heuristic` сохраняет прежнее именование без LLM.

## Что не изменяется
- SPECTER vectors и manifest.
- Исходный graph_edges.csv.
- Выбор resolution и итоговые назначения Leiden.
- Основное `.venv`: Ollama вызывается по HTTP, отдельные Python ML-зависимости не устанавливаются.

## Запуск
Установить Ollama для Windows, затем выполнить `ollama pull qwen3.5:4b`. После этого обычный запуск `RUN_AUTO_TOPIC_DISCOVERY.ps1` по умолчанию использует LLM.
