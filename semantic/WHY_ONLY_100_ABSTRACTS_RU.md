# Почему было найдено только 100 аннотаций

По логу повторного запуска можно установить следующее:

1. `OpenAlex API key configured: False` — запросы выполнялись без персонального ключа.
2. Первый же `OpenAlex title lookup` вернул HTTP 429 с сообщением `Insufficient budget ... $0 remaining`. Общий бесплатный бюджет запросов OpenAlex для текущего IP уже был исчерпан. Поэтому модуль остановил все дальнейшие обращения к OpenAlex.
3. `OpenAlex batches: 0` — записи, которым ещё требовалось обогащение, не удалось обработать пакетным поиском по распознанным DOI/OpenAlex ID; выполнение перешло к поиску по заголовкам.
4. В прежней версии Crossref был включён в конфигурации, но запускался только при `not openalex_failed`. Следовательно, HTTP 429 OpenAlex фактически отключал и Crossref fallback. Это ошибка логики, а не отсутствие Crossref в настройках.
5. Прежний предел OpenAlex title lookup был 300 за запуск, а Crossref обрабатывал только DOI (не искал по заголовкам) и имел лимит 100. Поэтому даже без 429 прежняя конфигурация не могла охватить все 1870 публикаций.
6. Число 100 — это найденные в локальных данных и/или уже сохранённом кэше записи; по представленному выводу текущий OpenAlex не добавил к ним новых аннотаций. Для точного распределения источников нужно смотреть `abstract_enrichment_report.json` → `abstract_source_counts`.

## Что исправлено в Hotfix 1.1.2

- Crossref запускается независимо от состояния OpenAlex, в том числе после HTTP 429.
- Добавлен Crossref title lookup через `query.bibliographic` для публикаций без DOI.
- Абстракт прикрепляется только при коэффициенте совпадения заголовка ≥ 0.92.
- Лимиты по умолчанию увеличены до 900 поисков заголовка OpenAlex и 1870 поисков заголовка Crossref; DOI Crossref тоже может обработать до 1870 записей.
- Добавлены отдельные счётчики запросов, совпадений, отклонённых совпадений и найденных записей без abstract.

## Почему нельзя обещать 1870/1870

OpenAlex и Crossref — библиографические агрегаторы. Не каждый издатель депонирует аннотацию, а Crossref хранит то, что издатели передали в метаданных. Поэтому корректная цель — найти максимально возможное число аннотаций, не прикрепляя чужие тексты. Работы без доступных аннотаций требуют локальных PDF/полных текстов или дополнительного источника открытых репозиториев.

## Лимит бесплатного OpenAlex

По текущей официальной документации OpenAlex бесплатный аккаунт получает $1 API-бюджета в день; без ключа действует существенно меньший общий бюджет на IP. Поисковый запрос `/works?search=` стоит около $1 за 1000 вызовов. 900 запросов оставляют небольшой запас в дневном бюджете. При необходимости оставшиеся записи обрабатываются следующим запуском после сброса бюджета или через дополнительный prepaid budget.

Документация: https://help.openalex.org/api/authentication/ и https://help.openalex.org/access/example-costs/
