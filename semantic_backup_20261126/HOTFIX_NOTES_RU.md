# Изменения: модельное семантическое именование

## Что добавлено
- Добавлен локальный Ollama-клиент на стандартной библиотеке Python (`urllib`), без установки дополнительных Python-пакетов.
- Модель по умолчанию: `qwen3.5:4b`.
- При старте проверяются доступность API, наличие выбранной модели, её digest и версия Ollama.
- После завершения Leiden для каждого сообщества формируются русское и английское названия, краткое описание и примечание о неоднородности.
- Evidence включает ключевые фразы YAKE/RAKE/contrastive TF-IDF, домены, до десяти публикаций с центроидно-доменным и farthest-first отбором, доступные аннотации/выдержки.
- В Streamlit выводятся описание, примечание и метод именования.
- В `topic_label_generation.json` сохраняются поданные модели evidence и её ответы.
- Режим `-Labeler heuristic` сохраняет прежнее именование без LLM.

## Что не изменяется
- SPECTER vectors и manifest.
- Исходный graph_edges.csv.
- Выбор resolution и итоговые назначения Leiden.
- Основное `.venv`: Ollama вызывается по HTTP, отдельные Python ML-зависимости не устанавливаются.

## Запуск
Установить Ollama для Windows, затем выполнить `ollama pull qwen3.5:4b`. После этого обычный запуск `RUN_AUTO_TOPIC_DISCOVERY.ps1` по умолчанию использует LLM.


# Расширение: доказательное семантическое именование

## Получение текстовых доказательств
- Добавлен `paper_evidence.py`: поиск локальных аннотаций/текстов в CSV, TSV, Parquet, Excel, JSONL и JSON внутри `data/` и `artifacts/`.
- Сопоставление идёт по `document_id`, DOI, OpenAlex ID и поддерживаемым внешним ID с проверкой порядка/уникальности идентификаторов.
- Для пропусков используется OpenAlex batch API (до 100 идентификаторов на запрос); abstract inverted index восстанавливается в нормальный текст.
- Ограниченный резервный поиск Crossref применяется к DOI, для которых не найдено аннотаций в OpenAlex. Если постоянных ID нет, допускается строгий OpenAlex-поиск по заголовку с порогом совпадения 0.90.
- Положительные ответы кэшируются в `artifacts/cache/topic_abstracts/paper_abstract_cache.json`; отрицательные результаты title-search — на 90 дней.
- При сетевой ошибке OpenAlex дальнейшие удалённые запросы останавливаются; Crossref прекращается после двух последовательных ошибок. Успешный ответ сбрасывает счётчик ошибок.
- При отсутствии DOI/OpenAlex ID лимит поисков по заголовкам распределяется round-robin по доменам; отрицательный кэш истекает через 90 дней.
- Внешним API передаются DOI/OpenAlex ID, а только при их отсутствии — публичный заголовок для точного поиска. Полные тексты и локальные аннотации корпуса не отправляются.

## Улучшение интерпретации
- Представители сообщества отбираются по близости к центроиду, покрытию доменов и farthest-first разнообразию (до 10 публикаций).
- Qwen получает аннотации/выдержки и частоты доменов, если они доступны.
- Модель формирует исследовательское ядро, подтемы, методы, объекты, описание, русское и английское название.
- Добавлен второй критический проход той же модели: проверка неподтверждённых утверждений, пропущенных направлений и неоднородности. Это не независимая экспертиза.
- Список подтверждающих заголовков сверяется с точными заголовками входного evidence.
- Ошибка генерации одной темы не обрывает весь запуск: тема получает явный резервный label и `review_required`.

## Streamlit
- Показаны покрытие аннотациями, уровень evidence, решение критического прохода, неподтверждённые claims, пропущенные направления и подтверждающие публикации.
- Аннотации и источники текста доступны в карточке темы и в экспортируемом `paper_evidence.csv`.

## Тесты
- Добавлены unit-тесты локального DOI-сопоставления, восстановления OpenAlex abstract, OpenAlex batch/cache, Crossref fallback, обработки сетевой ошибки и формирования профиля тем.
- Тесты запускаются командой `python -m unittest discover -s tests -v` из каталога пакета.

## Не меняется
- Контрольный граф, Leiden assignments, resolution, SPECTER embeddings и координаты существующей 2D-проекции.
- Зависимости основного ML-окружения, кроме уже существующего набора надстройки.

## Контроль и воспроизводимость
- Добавлены статусы `accepted`, `revised`, `review_required`, оценка поддержки и evidence-grade, а также списки неподтверждённых утверждений и возможных пропущенных направлений.
- Второй проход делает та же Qwen; это критический self-review, не независимая экспертиза.
- Отрицательные результаты title-search автоматически устаревают через 90 дней.
- При временных ошибках Crossref цикл останавливается только после двух последовательных ошибок; успешный ответ сбрасывает счётчик.
- Streamlit показывает взвешенное покрытие аннотациями всего корпуса и доказательную детализацию каждой темы.
